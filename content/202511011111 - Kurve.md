# Definition
Eine Kurve (oder ein Weg) ist eine stetige Abbildung $\gamma : [a, b] \to \mathbb{C}$ wobei $a, b \in \mathbb{R}$ mit $a \le b$. Hierbei heißen $\gamma(a)$ und $\gamma(b)$ Anfangs- bzw. Endpunkt von $\gamma$. Eine Kurve $\gamma$ heißt
(i) geschlossen, falls $\gamma(a) = \gamma(b)$.
(ii) einfach geschlossen, falls $\gamma(s) = \gamma(t)$ genau dann, wenn $s = t$ oder $\{s, t\} = \{a, b\}$.
(iii) stückweise $C^1$ (d.h. stückweise stetig differenzierbar) falls $a =: t_0 < \dots < t_{m+1} := b$ existieren, so dass die Einschränkung $\gamma_j = \gamma|_{[t_j, t_{j+1}]}$ für jedes $0 \le j \le m$ eine $C^1$ (also stetig differenzierbare) Funktion ist.
Das Bild $\text{im}(\gamma) \subset \mathbb{C}$ der Kurve ist die Menge
$$ \text{im}(\gamma) := \{\gamma(t) \mid t \in [a, b]\}. $$
