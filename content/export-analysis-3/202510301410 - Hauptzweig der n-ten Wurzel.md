# Definition
Sei $n \in \mathbb{N}$. Die Abbildung
$$
\sqrt[n]{\cdot}: \mathbb{C} \to \mathbb{C}, \quad z \mapsto \sqrt[n]{z} := 
\begin{cases}
\sqrt[n]{|z|}e^{i\text{Arg}(z)/n}, & \text{falls } z \neq 0 \\
0, & \text{falls } z = 0
\end{cases}
$$
wird Hauptzweig der n-ten Wurzel genannt.
