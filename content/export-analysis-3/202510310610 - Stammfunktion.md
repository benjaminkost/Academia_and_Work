# Definition
Sei $U \subset \mathbb{C}$ offen. Eine Stammfunktion einer Funktion $f : U \to \mathbb{C}$ ist eine in $U$ komplex differenzierbare Funktion $F : U \to \mathbb{C}$, die
$$F'(z) = f(z) \quad \text{für alle } z \in U$$
erfüllt.
