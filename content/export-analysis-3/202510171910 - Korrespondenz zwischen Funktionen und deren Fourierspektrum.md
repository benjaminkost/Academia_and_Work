# Definition
Die Korrespondenz zwischen Funktionen und deren Fourierspektrum ist kompatibel mit gewissen Operationen, gegeben durch folgende Tabelle:

| Operation auf Funktion     | auf Spektrum                                       |
| :------------------------- | :------------------------------------------------- |
| Linearkombination          | Linearkombination                                  |
| Komplexkonjugation         | Reflektion (Spiegelung an 0) & Komplexkonjugation  |
| Zeitumkehr                 | Reflektion                                         |
| Verschiebung (Translation) | Drehung der Spektralwerte (in der komplexen Ebene) |
Streckung ändert das Fourierspektrum nicht:

**Lemma 1.1.34.** (Streckung) Sei ${\gamma > 0}$. Das Fourierspektrum der Funktion
${t \to f(\gamma t)}$ ist ${\{c_k\}_{k\in\mathbb{Z}}}$.
