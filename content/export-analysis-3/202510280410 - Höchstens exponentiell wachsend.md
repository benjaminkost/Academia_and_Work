# Definition
Eine Funktion $f : [0, \infty) \to \mathbb{C}$ ist höchstens exponentiell wachsend, falls $C > 0$ und $\sigma \in \mathbb{R}$ existieren, so dass
$$
|f(t)| \le Ce^{\sigma t} \quad \text{für alle } t > 0.
$$
Das Infimum $\sigma_0$ aller möglichen $\sigma$-Werte in (1.65) heißt Konvergenzabszisse von $f$.
