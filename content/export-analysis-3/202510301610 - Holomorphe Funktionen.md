# Definition
Sei $U \subset \mathbb{C}$ offen. Eine Funktion $f: U \to \mathbb{C}$ heißt holomorph auf $U$ genau dann, wenn $f$ auf $U$ komplex differenzierbar ist. Falls $U=\mathbb{C}$ heißt $f$ auch eine ganze Funktion.
