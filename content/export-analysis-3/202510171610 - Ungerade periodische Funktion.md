# Definition
Sei ${f : \mathbb{R} \to \mathbb{C}}$ T-periodisch. Dann ist ${f}$
**ungerade** genau dann, wenn ${f(T/2 + t) = -f(T/2 - t)}$ für alle ${t \in \mathbb{R}}$. (1.14)
Eine T -periodische Funktion f ist genau dann ungerade, wenn der Graph von f am Punkt (T /2, 0) spiegelbar ist.[^1]
