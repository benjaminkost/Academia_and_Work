# Bemerkungen
Ist
$$f(z) = \sum_{k=-\infty}^\infty c_k(z-z_0)^k$$
die Laurent-Reihe von $f$ auf $A_{0,r}(z_0)$, dann ist das Residuum gleich
$$\text{Res}_{z_0}(f) = c_{-1}.$$
Dies folgt unter Verwendung des Fundamentalintegrals ([[202511011511 - Das Fundamentalintegral|Lemma 2.5.4]]) und gleichmäßiger Konvergenz (bzw. aus der Formel für $c_k$ von [[202511101211 - Laurent-Reihenentwicklung auf Kreisringen|Theorem 2.9.4]]).
