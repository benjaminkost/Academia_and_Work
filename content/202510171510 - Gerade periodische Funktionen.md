# Definition
Sei ${f : \mathbb{R} \to \mathbb{C}}$ T-periodisch. Dann ist ${f}$
**gerade** genau dann, wenn ${f(T/2 + t) = f(T/2 - t)}$ für alle ${t \in \mathbb{R}}$ (1.13)
Eine T -periodische Funktion f ist also genau dann gerade, wenn der Graph von f unter Spiegelung an der Gerade t = T /2 invariant bleibt. [^1]
